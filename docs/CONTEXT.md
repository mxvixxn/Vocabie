## 1. 한 문단 요약

**Vocabie**는 **클래스카드(ClassCard) 방식의 단어 암기 iOS 앱**입니다.
"학교를 졸업해 더 이상 선생님의 '클래스'가 없어도, 혼자서 클래스카드처럼 외우고 싶어서 직접 만든 앱"이 출발점이에요.

**암기 → 리콜 → 스펠** 3단계로 반복 학습하고, 엑셀·CSV·텍스트·마크다운을 붙여넣거나 파일로 불러와 수백 개 단어를 한 번에 넣을 수 있습니다.

- 저장소: https://github.com/mxvixxn/Vocabie (브랜치 `main`)
- 로컬 경로: `~/Desktop/Vocabie`
- **안드로이드판이 따로 있습니다** → `~/Desktop/VocabieAndroid` (Flutter, 별도 코드베이스). 아래 6절 참고
- UI 문구는 한국어, 다정한 존댓말 톤

## 3. 데이터 구조 — 3단 계층

```
Notebook (단어장)  →  VocabSet (세트)  →  Vocab (단어 카드)
```

2026-08-01에 **단어장·세트 2단계 구조로 개편**됐습니다. 예전 문서에 세트만 나오면 옛날 구조입니다.

카드마다 **별 3개(암기·리콜·스펠)** 로 숙련도를 표시하고, `lapses`·`timesWrong` 같은 오답 데이터가 쌓이고 있습니다.

## 4. 구현된 기능

- 🧠 **3단계 학습** — **암기**(플래시카드, 1차 노출) → **리콜**(4지선다 인출) → **스펠**(뜻 보고 타이핑)
  - 리콜: 틀려도 벌하지 않고 틀린 카드만 뒤에서 다시 반복
  - 스펠: 대소문자·공백·특수문자·슬래시 무시하는 **관대한 채점** + 힌트
- 📥 **대량 입력** — 엑셀/구글시트 복사 붙여넣기(탭 인식), CSV·TXT·MD 파일
  - 구분자 자동 감지: 탭 / 쉼표 / 대시 / 콜론 / 등호 / 여러 칸 공백 / 마크다운 표·목록
  - 추가 전 **미리보기**, 열(단어↔뜻) 스왑 가능
  - **붙여넣기 한 번으로 세트 여러 개 생성** (최신 기능)
- 🔁 **간격 반복** — SM-2 변형, 날짜 기반 복습 + 매일 복습 알림
- 🔊 **발음 듣기** — 무음 모드에서도 재생되는 TTS
- ⭐ **마스터리** — 카드별 별 3개, 단어장별 완료율
- 🔄 **방향 전환** — 영→뜻 / 뜻→영
- 📦 보관함, 묶음(10개) 학습, 학습 순서 옵션, 테마 전환, 내보내기

여러 뜻이 있는 단어는 `/`나 `,`로 구분된 답을 **모두 정답 인정** (예: `color / colour`).

## 5. ★ 결정해 둔 것 (다시 논의하지 않기)

이 원칙에 어긋나는 제안은 하지 마세요. 이미 결론이 난 사항입니다.

- **유리(Liquid Glass)는 조작 층에만.** 단어·뜻·목록 같은 콘텐츠에는 재질을 쓰지 않는다
- **커스텀 유리 금지.** 순정 `glassEffect`만 쓴다 *(Moodie Sky 설계 문서 승계)*
- **하단 패널은 바닥에서 띄운다.** 붙이면 화면의 일부로 읽힌다
- **오답에 빨강·✗를 쓰지 않는다.** 조용히 흐려지고 정답만 켜진다
- **암기 모드는 복습 스케줄을 만들지 않는다.** 노출이지 인출이 아니므로
- **자기 평가를 받지 않는다.** 몇 번 만에 맞혔는지로 자동 채점
- **네이버 등 사전 음성을 무단 사용하지 않는다.** 약관·저작권 위반

## 7. 안드로이드판과의 관계

`~/Desktop/VocabieAndroid` — **Flutter로 따로 만드는 별도 앱**입니다.

- **코드를 공유하지 않습니다.** iOS의 유리 감성 디자인을 포기하지 않으려고 Flutter로 통합하지 않기로 결정했어요.
- 두 앱을 잇는 **유일한 계약은 JSON 백업 파일 형식** 하나뿐입니다.
- → **iOS의 JSON 백업 포맷을 바꾸면 안드로이드판이 깨집니다.** 포맷 변경은 양쪽을 함께 고려해 주세요.
- 안드로이드판은 아직 **설계만 끝나고 구현 전** 상태입니다 (`lib/main.dart` 하나뿐).
