# 📚 Vocabie (워디)

> **"클래스카드처럼 외우고 싶어서 직접 만든 단어 암기 앱."**
> Vocabie는 학교를 졸업해 더 이상 선생님의 '클래스'가 없어도, 나 혼자서 **암기 → 리콜 → 스펠** 방식으로 단어를 반복 학습할 수 있는 iOS 앱이에요.
> CSV·엑셀·텍스트·마크다운을 붙여넣거나 파일로 불러와 수백 개의 단어도 한 번에 수록할 수 있어요.

<br>

## ✨ 주요 기능 (Key Features)

* **🧠 3단계 학습 (ClassCard-style)**
  * **암기 (Memorize)** — 카드를 넘기며 뜻을 익히는 1차 노출 단계 (플래시카드).
  * **리콜 (Recall)** — 4지선다 객관식으로 능동적으로 회상하는 단계. 틀려도 벌하지 않고, 틀린 카드만 뒤에서 다시 반복돼요.
  * **스펠 (Spell)** — 뜻을 보고 철자를 직접 타이핑. 대소문자·공백·특수문자·슬래시를 무시하는 관대한 채점 + 힌트 기능.
* **📥 대량 단어 입력 (Bulk Import)**
  * **붙여넣기**: 엑셀·구글시트에서 셀을 복사해 붙여넣으면 탭 구분으로 자동 인식.
  * **파일 불러오기**: CSV, 텍스트(TXT), 마크다운(MD) 파일 지원.
  * **구분자 자동 감지**: 탭 / 쉼표 / 대시(-) / 콜론(:) / 등호(=) / 여러 칸 공백 및 마크다운 표·목록까지 자동 파싱.
  * 추가 전 **미리보기**로 파싱 결과를 확인하고, 필요하면 열(단어↔뜻)을 바꿀 수 있어요.
* **⭐ 마스터리 & 진도**
  * 카드마다 별 3개(암기·리콜·스펠)로 숙련도를 표시하고, 단어장별 완료율을 한눈에 보여줘요.
* **🔄 방향 전환**: 영단어 → 뜻 / 뜻 → 영단어 방향을 자유롭게 선택.

<br>

## 🛠️ 기술 스택 (Tech Stack)

* **Language**: Swift
* **UI**: SwiftUI
* **Data**: SwiftData (로컬 영구 저장)
* **Concurrency**: `@MainActor` · `@Observable`
* **Minimum**: iOS 18.0+


## 📥 지원하는 입력 형식 예시

```
apple	사과            ← 탭 구분 (엑셀 복사)
banana, 바나나          ← CSV
cat - 고양이            ← 대시
dog : 개                ← 콜론
| word | 뜻 |           ← 마크다운 표
- elephant 코끼리       ← 마크다운 목록
```

여러 뜻이 있는 단어는 스펠 채점 시 `/` 나 `,` 로 구분된 답을 모두 정답으로 인정해요 (예: `color / colour`).
